SuapEdu · Mapa inicial

Conheça as principais funções

Este guia apresenta um mapa inicial das funções acadêmicas mais importantes para o começo do curso. Algumas abas poderão permanecer vazias ou ser utilizadas somente em etapas futuras.

Abrir o SUAPVer primeiro acessoEmitir documentos
As informações aparecem progressivamente

No começo do semestre, horários, avaliações, notas ou disciplinas podem ainda estar vazios enquanto professores e setores concluem os registros.

Pendência inicial: Caracterização Socioeconômica

Preenchimento prioritário

O SuapEdu apresenta automaticamente esse questionário entre as pendências do estudante. Responda-o assim que possível, preencha com atenção e revise as respostas antes de salvar.

A caracterização reúne informações pessoais, familiares, econômicas, habitacionais, de transporte, saúde e acesso à tecnologia.

Caminho: Ensino › Dados do Aluno › Caracterização Socioeconômica

Menu Ensino

No menu lateral, abra Ensino. É nessa área que ficam os principais acessos acadêmicos do estudante.

Nota visual: algumas capturas do ambiente de treinamento usam vermelho. No ambiente real, a paleta padrão da barra lateral é cinza-chumbo. Os nomes e caminhos permanecem os mesmos.

Minhas Disciplinas

Use essa área para verificar os componentes e diários associados ao período letivo selecionado.

Caminho: Ensino › Minhas Disciplinas
O que é um diário?

É o espaço acadêmico da disciplina no qual são vinculados registros como aulas, avaliações, notas e frequência.

Locais e Horários de Aula

O sistema oferece dois caminhos para a mesma consulta. Use o que for mais fácil.

Caminho 1: Ensino › Locais e Horários de Aula
Caminho 2: Dados do Aluno › Locais e Horários de Aula / Atividade

Selecione o período letivo correto. Horários e locais podem ser complementados ou ajustados no início do semestre.

Agenda de Avaliações

Mostra as avaliações já cadastradas pelos professores. No menu lateral, a entrada correspondente aparece como Minhas Avaliações.

Caminho: Ensino › Minhas Avaliações

Uma tela vazia significa apenas que ainda não há avaliações cadastradas para o período selecionado.

Boletim

O boletim reúne os registros acadêmicos disponibilizados para cada componente. Há dois caminhos de acesso.

Caminho 1: Ensino › Boletins
Caminho 2: Dados do Aluno › Boletins

Selecione o período letivo. Antes do início dos lançamentos, o sistema pode informar que ainda não existe boletim para o período.

Histórico

O histórico apresenta o percurso acadêmico registrado no sistema. Há dois caminhos de acesso.

Caminho 1: Ensino › Histórico Escolar
Caminho 2: Dados do Aluno › Histórico
Consulta na tela ou documento?

Não confunda a aba Histórico com o Histórico Parcial emitido na área de documentos acadêmicos. O segundo é um arquivo com autenticação eletrônica.

Documentos acadêmicos com autenticação eletrônica

O SuapEdu permite emitir diretamente os documentos acadêmicos disponibilizados para o vínculo. Há três caminhos para chegar à mesma lista.

Documentos exibidos no sistema:
  • Declaração de Vínculo
  • Histórico Parcial
  • Declaração de Carga Horária Integralizada
  • Declaração de Matrícula
  • Declaração de Matrícula com disciplinas cursando
  • Comprovante de Dados Acadêmicos
Caminho 1 — principal: Ensino › Dados do Aluno › botão Documentos
Caminho 2 — alternativo: Ensino › Dados do Aluno › botão Minha Conta › Meus documentos
Caminho 3 — atalho direto: ícone de usuário ao lado do nome, na barra lateral › Meus documentos

Os três caminhos levam à mesma página de documentos acadêmicos disponíveis para o vínculo.

Qual caminho usar?

Para o primeiro uso, o caminho pelo menu Ensino é o mais fácil de reconhecer. Depois, você pode usar os atalhos por Minha Conta ou pelo ícone de usuário.

Caminho 1 — pelo menu Ensino

Caminho 2 — pelo botão Minha Conta

Caminho 3 — pelo ícone de usuário na barra lateral

Clique no ícone de usuário ao lado do seu nome. A página Minha Conta será aberta; nela, selecione Meus documentos.

Resultado: página Meus Documentos SUAP

Autenticidade e validade dos documentos

Os documentos emitidos pelo SUAP possuem autenticação eletrônica e podem ter sua autenticidade conferida por meio das informações apresentadas no rodapé. Por isso, não dependem de assinatura manual da CCA.

Todo documento também apresenta no rodapé a data de emissão, o código verificador, o emissor e a data de validade. Depois do vencimento, basta emitir uma nova via pelo próprio sistema.

Dados do Aluno

A ficha do estudante reúne várias abas. Nem todas serão utilizadas desde o início do curso, mas esta é uma área central do SuapEdu.

Caminho: Ensino › Dados do Aluno
  • Dados Acadêmicos e Dados Pessoais.
  • Requisitos de Conclusão.
  • Boletins e Histórico.
  • Locais e Horários de Aula / Atividade.
  • Grade Curricular.

A aba Documentos e Processos não é o caminho para emitir os documentos acadêmicos. Para isso, use o botão Documentos; o caminho Ensino › Dados do Aluno › botão Minha Conta › Meus documentos; ou o ícone de usuário ao lado do nome, na barra lateral.

As demais abas podem permanecer vazias, depender de outros setores ou ser utilizadas apenas em etapas futuras do curso.

Antes de pedir ajuda

  • Confirme se selecionou o período letivo correto.
  • Leia a mensagem apresentada na tela.
  • Registre uma captura sem expor senha ou dados desnecessários.
  • Informe nome, matrícula, curso, função acessada e descrição objetiva do problema.
  • Se o problema persistir, envie uma mensagem para cca.baturite@ifce.edu.br, com sua identificação e a captura da tela.
